# Snap-it Product Roadmap

See [ROADMAP.md](ROADMAP.md) for the complete roadmap.

## Summary

- **Phase 1: Foundation & Camera Core (Completed)**
  TanStack Start, Radix UI primitives, useCamera adapter, 60fps CSS filter engine, Supabase integration.

- **Phase 2: Social Graph & Privacy Hardening (Completed)**
  Zero-location discovery with interest tags, mutual blocking triggers, 24h story expiry, direct chat.

- **Phase 3: Real-Time Communication & Snaps (In Progress)**
  Direct one-time ephemeral snaps, typing indicators, presence, Web Push notifications.

- **Phase 4: Native Mobile App (Planned)**
  Capacitor / React Native mobile wrappers, native hardware camera controls, local encrypted cache.

- **Phase 5: Filter Studio & Community Effects (Future)**
  User-created CSS filters, community presets, 2D lens landmark tracking.
